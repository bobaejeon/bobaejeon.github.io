**Overview**
- Built an Android app to support a volunteer program for caring for street trees in Seoul, South Korea

- Provided features like program sign-up, tree info display, and updating tree images through volunteer reports
- Responsible for database design and Android development
- Skills: Android Studio, Java, Firebase
